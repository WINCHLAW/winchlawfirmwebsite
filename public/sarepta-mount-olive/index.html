The public record and more about the project

One line, two names. Landowners call it the Sarepta to Ruston line. Entergy calls it the Mount Olive to Sarepta 500 kV Transmission Project. The Louisiana Public Service Commission approved it in August 2025 in Docket U-37425, the same proceeding as Meta’s data-center power supply. Routes can change, so a parcel should be checked against current route materials.
