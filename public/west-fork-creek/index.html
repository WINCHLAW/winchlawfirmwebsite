The public record and more about the project

One project, several names. Public reporting and route materials call it the West Fork Creek–Boeuf 500-kV Transmission Project or Project Omega. Louisiana Public Service Commission filings use West Fork Creek–St. Landry 500 kV, within LPSC Docket U-37882. Routes can change, so a parcel should be checked against current route materials.
